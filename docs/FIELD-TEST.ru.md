# Полевой тест Deloresh Objects (для сотрудников)

Цель: пройти рабочие сценарии **на телефоне / планшете / ПК** и зафиксировать,
что удобно, что ломается и чего не хватает. Это не экзамен — ищем пробелы.

## Ссылка

**http://94.242.58.24/**

- Водитель после входа попадёт сразу в кабинет:  
  **http://94.242.58.24/driver**
- Логин и пароль выдаёт руководитель (учётки уже заведены по ФИО).

## Как зайти с телефона

1. Откройте ссылку в **Chrome** (Android) или **Safari** (iPhone).
2. Введите логин латиницей (фамилия, например `Gevenyan`) и пароль.
3. Если после обновления сайта «всё старое» / нет кнопки «Удалить» / не грузятся
   задачи: закройте вкладку полностью и откройте ссылку снова. На iPhone при
   залипании: Настройки → Safari → «Очистить историю и данные» только для этого
   сайта (или обновить страницу с удержанием → «Без контента»).
4. **После смены паролей/входа на сервере** (сент. 2026): выйдите и войдите снова —
   без нового входа задачи с других устройств не подтянутся.
5. По желанию: «На экран „Домой“» / установить как приложение (на HTTP не
   везде доступно — обычная вкладка браузера тоже ок).

## С чего начать (общий минимум, 5–10 мин)

- [ ] Вход работает, видно своё ФИО / роль.
- [ ] Открывается нужный раздел (задачи / объекты / водитель / спецтехника).
- [ ] После обновления страницы данные **не пропали** (отчёт, заявка, фото, задача).
- [ ] На телефоне кнопки нажимаются пальцем, текст читается.
- [ ] На **втором устройстве** (другой телефон / ПК) под тем же логином видно то же
      (задача, комментарий, фото на объекте) — в течение ~20 сек или после обновления.

Дальше — чек-лист **по своей роли**.

## Задачи (все роли кроме чистого водителя)

- [ ] Список задач открывается, фильтры понятны.
- [ ] Создать задачу (если роль позволяет) → у исполнителя на **другом телефоне** она появилась.
- [ ] Открыть задачу → чат: текст, файл, фото.
- [ ] Голос: на **HTTP** микрофон браузер часто блокирует — выберите аудио-файл;
      после HTTPS запись с микрофона заработает.
- [ ] Исполнитель: «В работу» / «Готово»; создатель: кнопка **Удалить** (с подтверждением).
- [ ] Непрочитанные (бейдж) сбрасываются после открытия и видны с другого устройства.

## Бригадир

Объекты → выбрать объект (удобно начать с **Брусилова**).

- [ ] План / смена на день: видно, понятно ли, чего не хватает.
- [ ] **Отчёт бригадира**: создать, сохранить, обновить страницу — отчёт на месте.
- [ ] Прикрепить **фото** с объекта; после обновления фото осталось.
- [ ] **Поставки на сегодня**: открыть, принять / отметить (если есть рейс).
- [ ] **Чертёж (DWG)**: статус «План готов» → открыть план, pinch-zoom двумя пальцами.
      Стандарт загрузки для всех объектов: `docs/DWG-STANDARD.ru.md`.
- [ ] На плане: выделить зону / линию, поставить статус (выполнено / ЦККБ / замечание),
      комментарий — сохранить и проверить после обновления.
- [ ] На мобильном: добавить / удалить вершину контура (кнопки и тап по ребру).

## Диспетчер

- [ ] Объект → зона рейсов / точка выгрузки.
- [ ] Назначить / увидеть рейс водителю.
- [ ] Водитель в своём кабинете видит задачу (согласовать с водителем по телефону).

## Водитель / машинист

Вход → кабинет **/driver**.

- [ ] Список рейсов на сегодня понятен.
- [ ] Открыть рейс, отметить выполнение / поделиться в мессенджер (если нужно).
- [ ] Навигация и текст удобны одной рукой.

## Снабжение

- [ ] Объект → **заявка снабженцу**: создать, сохранить.
- [ ] После обновления страница заявка на месте.
- [ ] Расход / материалы: понятно ли, чего не хватает в учёте.

## Начальник участка / ПТО / руководство

- [ ] Список объектов и статусы.
- [ ] Карточка объекта: все зоны (смена, снабжение, рейсы, чертежи).
- [ ] **Спецтехника**: реестр, карточка единицы, правки (где есть).
- [ ] Чертёж: статусы зон, расчёт материалов к заказу — читаемость на ПК и планшете.

## Как писать о пробеле (обязательный формат)

В чат полевого теста одним сообщением:

```
Роль: бригадир / водитель / …
Устройство: iPhone 13 / Samsung … / Windows …
Раздел: объект Брусилова → отчёт / чертёж / поставки / …
Что делал: …
Ожидал: …
Получил: … (или «непонятно / кнопки нет / вылетело»)
Скрин: (если можно)
```

Пометки: **блокер** (нельзя работать) / **мешает** / **хотелка**.

## Что уже известно (не считать сюрпризом)

- Часть справочников / KPI спецтехники пока **демо**; живые заявки/отчёты/фото/задачи уходят на сервер.
- **Приёмка техники** — отдельная панель Streamlit (`:8501`), не внутри SPA.
- Ссылка по IP (**HTTP**) — без «зелёного замочка»; микрофон и полноценный PWA ограничены, пока нет HTTPS/домена.
- У каждой роли свой экран: бригадир не видит всё как директор, водитель — только кабинет.
- Спецтехника/объекты (часть полей) синхронизируются, но базовые «цифры плана» могут быть mock.
