# Когда появятся полные данные

Пока в приложении **демо-парк** и **демо-объекты** (+ то, что вы уже добавили вручную в браузере). Ниже — что принести, когда будут реальные списки.

## Объекты

Для каждого объекта желательно:

| Поле | Зачем |
|------|--------|
| Название | Карточка и поиск |
| Адрес / площадка | Шапка объекта |
| Статус (нормально / внимание / критично) или факты для расчёта | KPI и фильтр |
| План / факт / срок | Прогресс на карточке |
| Контакты бригадира / снабжения | Зоны объекта |

Формат на старте: **Excel** или таблица. Импорт можно сделать отдельным скриптом → `sitesRepository` / будущий API.

## Спецтехника

| Поле | Зачем |
|------|--------|
| Класс (экскаваторы, самосвалы…) | Каталог парка |
| Госномер, название | Список и карточка |
| Срок ДК / техосмотра | «На контроле» |
| Срок страховки | «На контроле» |
| Пропуска (обязательные + сроки) | «На контроле» |
| Открытые ремонты | «На контроле» |

Пока технику можно **добавлять в UI** («Добавить технику») — счётчики на главной обновятся сами.

## Приёмка (панель Ameda)

URL дашборда: env `VITE_AMEDA_INSPECTION_DASHBOARD_URL` (например `http://…:8501/`). Без него карточка «Приём и учёт» на главной без внешней ссылки.

## Резервная копия уже введённого

В консоли браузера на сайте: `window.DELORESH_BACKUP` — см. `docs/RECOVERY.ru.md`.
